# Little Rest 0.3.0-beta.2 — clearer Trends on Android and iPhone

2026-10-23 · **Private Firebase Spark QA, not public release**.

The same Flutter sleep journal now has a calmer, more truthful Trends chart on Android and the installable iPhone Home Screen PWA at **https://little-rest-ios-qa.web.app**.

## What's improved

- Seven-day view shows bars **only for days with actual recorded sleep**. Missing days are stated separately: a blank day does not mean the baby slept zero hours.
- Recorded-day bars are scaled against the longest logged day, with a **minimum one-hour visual scale**, and do **not** indicate a clinical sleep target.
- Fixed a chart-fill layout defect that previously made bars appear blank even when records existed. Tested for nonzero painted height at 390px phone width.
- Relative bar length and label text are designed for narrow phones; dark and light themes use accessible contrast.
- All existing Baby 1 and additional baby sleep histories remain in their original separate immutable Firestore journal paths. No migration or deletion.

## Distribution

- **iPhone staging PWA:** Open https://little-rest-ios-qa.web.app in Safari, Share → Add to Home Screen → Open as Web App. After an update, fully close/reopen the PWA; a second launch may be needed to activate a refreshed service worker. No Apple signing expiration.
- **Android:** Install the signed staging APK from exact beta.2 source after its GitHub Actions build succeeds, using ADB **install -r** (not uninstall or clear data).
- Both connect to Firebase Spark staging project `little-rest-stage-jh-261020`; the dedicated PWA Hosting site does not overwrite the separate account-deletion site.

## Acceptance and limitations

The signed APK, GitHub CI and PWA artifact **must all be verified on the same source revision before rollout**. Browser smoke is evidence of desktop Chrome at iPhone width, **not physical Safari/iPhone confirmation**. Keep App Check, real two-device pairing, caregiver revocation, identity recovery, iPhone background/offline persistence, and privacy/security G2/G3 as open release gates.
