# Little Rest 0.3.0-beta.3 — browser-first mobile app

**2026-10-23 · Private QA candidate. Android + iPhone use one PWA. Production approval is still blocked.**

## Installation

**Same mobile URL:** https://little-rest-ios-qa.web.app

- **Android Chrome:** select the in-app **Install** card if Chrome offers it, or Chrome **⋮ → Add to Home screen → Install**.
- **iPhone Safari:** Share → Add to Home Screen → Open as Web App → Add. No weekly certificate renewal.
- Both can continue in a browser tab. Existing native Android staging remains optional; **do not uninstall it before syncing and verifying email account recovery**.

## Changes since beta.2

- Unified runtime flag **`USE_MOBILE_PWA`** for Android Chrome and iPhone Safari; old `USE_IOS_PWA` remains a compatibility alias to prevent rollout breakage.
- Install UI with a browser-native Chromium installation prompt on direct user gesture, clear iPhone manual instructions, installed-mode suppression, accessible dismissal and 30-day opt-out.
- Responsive, dark/light styled app-install guidance that is not shown inside standalone installed PWA.
- GitHub-hosted behavioral tests of iOS guidance, Android browser prompt, standalone suppression, dismissal; exact reviewed hosting artifact checks now require the install script and stable PWA origin identity.
- One cross-platform documentation path, with the existing Hosting origin kept unchanged. This avoids inadvertently splitting website data, Firebase sessions and PWA installed identity.
- Retains beta.2 seven-day sparse sleep chart, nonzero bar fills and Firefox/Chrome/Safari browser HTTP cache-safe code updates.

## Verified vs outstanding

**Must be green:** GitHub Flutter/analyzer/widget tests, Firebase Family Lite security/E2E, mobile PWA web build and exact-source install script checks. Do not deploy a newer SHA solely because an older web build passed.

**External acceptance still open:** physical installed Android Chrome PWA and physical installed Safari iPhone, offline queued edits and server acknowledgement on both, cold start on slow networks, caregiver owner grant/revocation, account recovery, App Check enforcement, accessibility/TalkBack/VoiceOver and privacy G2/G3 signoff. No production merge, billing change, data purge or background notification promises.
