# Little Rest v0.2.0-beta.2 — Spark Family Lite

**Stage:** signed Android staging APK installed; **G2/G3 still draft** · **No Cloud Functions, no Blaze billing** · **Code branch:** `feat/spark-family-lite`.

## The point of this release

Two parents can use **separate recoverable Firebase accounts** yet operate one immutable, synchronized sleep journal. The owner explicitly approves the caregiver's Firebase UID; the caregiver independently joins by the owner's UID. Neither account shares its password with the other.

### Added

- Firestore Security Rules for `personalSleep/{ownerUid}/caregivers/{caregiverUid}`: only the owner issues/revokes grants, verified-email caregivers alone may read/append, actor IDs remain genuine, cross-household and unverified access denied.
- A **permanent sharing marker** that blocks deletion by outdated personal-only clients; a separate irreversible server deletion fence makes concurrent re-creation impossible during erasure.
- Owner Approve / Revoke, caregiver Join / Leave and UID Copy UI; server-verified saved membership, a visible fail-closed verification gate, and immediate online revocation detection.
- The existing F1 immutable-operation sleep repository now separates owner scope from actual actor UID.
- Adversarial rules tests and dedicated two-account Flutter Android emulator test, including offline reconnect after revocation and deletion fencing.
- Detailed [Spark Family Lite runbook](../SPARK_FAMILY_LITE.md) and [security ADR](../ADR-0002-spark-family-lite.md).

### Still limited

- Only **synthetic QA data**; do not invite a real family before G2/G3 review and two physical devices test.
- A copy/paste pairing ID rather than QR scan. Matching UIDs to real people requires an out-of-band check.
- Only one other caregiver supported through the current UI; server Rules enforce owner-only grants but no global account seat count.
- An offline device may retain previously cached records; no Firebase service can remotely recall exports from a phone.
- On cold-start offline, the app blocks shared writes until membership can be reverified, instead of silently saving into a different parent's journal.
- iOS device signing and TestFlight distribution not yet available.
- Strict email verification / account recovery, shared-account deletion races and App Check enforcement require further acceptance.
